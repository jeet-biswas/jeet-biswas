## 🏗️ What I Build

I am interested in **complete AI engineering systems**, not just standalone
models.

### 🤖 Generative AI

Building LLM-powered applications that can understand requests, retrieve
information, generate responses, and interact with external systems.

### 🧩 Agentic AI

Designing AI agents that can use tools, call APIs, access data, and execute
multi-step tasks through structured workflows.

### 📚 RAG Systems

Connecting LLMs with documents, databases, embeddings, and retrieval
pipelines to build context-aware AI applications.

### ⚙️ AI Backend Systems

Building APIs and backend services that connect AI models with databases,
authentication, webhooks, external services, and applications.

### 🚀 AI Deployment & MLOps

Taking models and AI applications from development to deployment using
containers, APIs, CI/CD, and production-oriented infrastructure.

### 📡 Edge AI

Exploring lightweight AI systems designed to run on constrained devices
such as microcontrollers and Raspberry Pi.
